# Impor CSV/XLSX dengan staging

POST /app/api/imports menerima kind dan file: employees, branches, departments, jobs, rosters, leave_credits, compensation. Hak company sesuai domain diperlukan; batch hanya terlihat pembuat berizin. Berkas maksimal10MB/5000baris/50kolom, satu sheet XLSX. CSV UTF-8 comma-separated, tanggal ISO YYYY-MM-DD, boolean0/1; nomor identitas/rekening harus teks agar nol awal tidak hilang. XLSX ditolak bila ada formula, macro, externalLinks/embedded objects, path arsip mencurigakan, jumlah entry/ukuran ekspansi berlebih. Reader tidak menghitung formula. Ini bukan pemindai malware eksternal.

Upload menyimpan hash bisnis dan rows terenkripsi. Upload identik user/kind mengembalikan batch lama, bukan membuat data ganda. GET imports/{id} menyediakan headers/available_fields. POST {id}/map membawa mapping field_domain→header_sumber dan expected_version. Header harus unik; mapping tidak menerima field bebas. {id}/preview memvalidasi **semua** baris, menyimpan error_count dan maksimal200 detail row/column/reason/remedy, serta HMAC checksum. Preview menampilkan maksimal20 ringkasan tanpa nomor identitas penuh.

{id}/commit memerlukan checksum dan expected_version. Semua validasi domain diulang sambil memegang write lock; perubahan sejak preview mengembalikan409 tanpa profil parsial. Mutasi seluruh batch berada dalam satu transaksi termasuk audit, receipts dan draft verification. UUID retry identik tidak menulis ulang. background:true mengantre CommitImport, worker memeriksa kembali akun/security_version/role. Job gagal tidak menyimpan SQL/input pribadi ke failed_jobs; status batch meminta preview ulang. Worker300detik/1attempt; pembatasan5000baris belum merupakan pengesahan performa produksi.

Default hanya create, tidak overwrite. Duplikat employee_number/email/national ID dalam batch atau profil/request identitas sebelumnya menolak batch; arahkan ke person lama/alur rehire. Master/manager harus sudah diimpor lebih dahulu. Employee initial import membuat identity_change **draft** jika national_id tersedia; independent HR verification tetap wajib. Tidak membuat identitas verified langsung. Compensation opening menghasilkan draft workflow Finance, bukan approval atau histori pembayaran. Roster import menghasilkan draft untuk publikasi tersendiri; cuti opening memakai credit lot/ledger dan source_key unik. Tidak ada update organisasi/kompensasi tersembunyi melalui general profile.

Belum acceptance penuh: reusable template-file download, mapping/duplicate resolution interaktif/rehire lintas baris, opening payroll historis, job validasi file besar dan load/concurrency5000baris. Form preview lama belum terhubung ke API ini. Satu duplicate dalam tests membuat nol profil baru dan perubahan sumber setelah preview tidak membuat baris parsial.

# Laporan, ekspor privat dan pencarian

GET /app/api/reports/{kind}, kind attendance/overtime/leave_balances/contracts/lifecycle/assets/payroll/expenses. starts_on/ends_on eksklusif, maksimal62hari, opsional branch_id/department_id/employee_id/employment_status. Maksimal5000hasil; persempit filter jika berlebih. Attendance/overtime memakai EmployeeVisibility pada work date, sehingga pegawai keluar tetap ada dalam periode kerjanya. Leave balance hanya pemilik/HR scope, kontrak/lifecycle HR scope, aset IT company, payroll Payroll/Finance company, expenses Finance company. Role baca umum tidak membuka bank atau alasan medis/exit.

Presence adalah shift dengan effective_in dari clock valid atau koreksi disahkan. Late/early merupakan subset presence yang bisa beririsan; incomplete/conflict tetap flag tersendiri, tidak menghapus bukti hadir. DAY_OFF/ABSENT bukan presence. Report menyertakan definisi dan drill-down. Attendance/overtime closed memakai snapshot revision/hash serta nama saat close; perubahan projection/nama master tidak menulis ulang laporan. Drill-down attendance-snapshots/{id} memeriksa scope work date. Ledger saldo memakai entri yang tercatat sebelum cutoff, bukan state allocation hari ini.

POST reports/{kind}/exports menerima filter, format csv/xlsx, reason dan UUID. Worker BuildReportExport memeriksa ulang akun/security-version/role, menghasilkan data yang sama dengan report JSON, dan menyimpan byte terenkripsi beserta scope/hash. GET report-exports/{id} untuk status; {id}/download hanya pemilik berizin selama24jam. Izin dan semua record IDs diperiksa lagi saat download, jadi pindah team/cabut grant menolak file lama. CSV menetralkan formula, XLSX menetapkan setiap nilai sebagai string eksplisit. Export bukan instruksi bank. Queue worker diperlukan; error tidak menyalin rows privat ke failed_jobs.

GET search?q=...&as_of=YYYY-MM-DD mencari ringkasan pegawai, pengajuan, nomor dokumen dan aset. Query2–80karakter, wildcard literal di-escape, maksimal10hasil/type. Setiap kandidat melewati izin domain; payload terenkripsi, medical reason, bank dan nominal salary tidak diindeks. Scan kandidat workflow/dokumen dibatasi500 dan belum merupakan indeks pencarian berskala besar. Hasil menautkan endpoint nyata; layar preview tetap terpisah.

Belum acceptance: seluruh kombinasi filter historis finansial dan joiner/mover lintas departemen, skala/query-plan/N+1, saved reports, indeks besar, export cleanup scheduler dan UAT. Format report mata uang memakai integer sen IDR, tanpa membocorkan snapshot bank. Histori OFFBOARDING baru memiliki offboarding_from agar approval exit tidak mengubah status tahun-tahun sebelumnya.

# Fondasi approval dan operasi

Fondasi bersama ini menyediakan versi definisi, snapshot kandidat approver, tahap berurutan, keputusan atomik, penolakan self-approval, blocked approver, penugasan ulang beralasan, withdrawal sebelum final, idempotency receipts, inbox/outbox, retry email dan penyimpanan berkas privat. Domain diaktifkan hanya setelah handler nyata terdaftar; jenis tanpa handler ditolak, bukan disetujui tanpa efek. Handler sintetis hanya ada pada tests/Support.

Endpoint sesi/CSRF/MFA di bawah `/app/api`: workflow-definitions, requests, requests/{id}/{submit,decide,withdraw,reassign}, inbox, requests/{id}/attachments, attachments/{id}/download. Mutasi membawa UUID `Idempotency-Key` atau idempotency_key; perubahan state juga expected_version. Retry kunci/isian sama mengembalikan referensi hasil yang sama setelah pemeriksaan izin ulang; isian berbeda dengan kunci sama menghasilkan409. Payload privat dienkripsi dan tidak diserialisasikan ke daftar/detail. Domain menyediakan summary aman dan efek transaksi sendiri.

Definisi baru tidak mengubah request lama. Role kandidat dibatasi handler domain; kandidat disalin saat submit, actor dipastikan masih berizin saat keputusan. Kandidat kosong memblokir request dan membuat inbox HR, tanpa fallback ke orang pertama. HR company dapat menugaskan ulang request domain HR dengan alasan kepada aktor sah selain pengaju/subjek. Tahap berikut hanya aktif setelah sebelumnya disetujui; final handler dan decision/audit/outbox berada dalam satu transaksi. Request final memerlukan reversal domain terpisah.

Outbox hanya menyimpan event dan referensi tanpa alasan medis/nominal. Inbox unik per event/penerima dibuat bersama transaksi. Scheduler menjalankan `hris:dispatch-operations` setiap menit dan mengantre DeliverOutbox. Reminder24jam/escalation48jam saat ini memakai jam elapsed; kalender kerja dan preferensi/digest belum selesai. Tidak ada auto-approve. Email generik tidak memuat rincian privat. Delivery menggunakan lease, backoff, maksimum5attempts dan kode error tanpa menyalin pesan provider. Email secara teknis at-least-once pada crash setelah kirim sebelum status sent; Message-ID stabil membantu dedup, tidak merupakan jaminan exactly-once transport. Jalankan queue worker dan scheduler pada deployment; SMTP nyata belum diuji/dikirimi dalam pekerjaan ini.

Berkas saat ini menerima JPEG/PNG/PDF maksimal5MB; gambar harus benar-benar dapat didekode dan dibatasi dimensi/piksel. Nama penyimpanan acak di disk local privat; nama unggahan tidak dipakai sebagai path. Download selalu memeriksa request induk dan klasifikasi. Bukti cuti dibatasi ke pemilik/HR berizin, bukan manager. Tidak ada public storage link. Pemindai malware eksternal belum dikonfigurasi; MIME/decode bukan pemindai malware.

Suspension akun bertanggal terpisah dari hubungan kerja dan diperiksa pada runtime. Endpoint manajemen suspension masih harus diselesaikan; cuti tidak mengubah akses akun. Koneksi PostgreSQL memakai timezone kalender aplikasi secara eksplisit agar serialisasi timestamp Laravel tidak bergantung timezone host/database; timestamptz mempertahankan instant dan JSON datetime tetap memakai representasi UTC Laravel.

Tes PostgreSQL saat ini mencakup state berurutan, self-approval, efek/retry tunggal, key berbeda input, blocked approver, IDOR, data privat, release pada reject/withdraw, outbox dedup, inbox ownership, berkas salah/valid dan suspension runtime. Pengujian multi-proses dan beban belum disahkan. Ini fondasi, bukan penyelesaian seluruh backend/R1 atau koneksi seluruh layar statis.
